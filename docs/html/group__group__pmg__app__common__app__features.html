Macro Definition Documentation

◆ CY_APP_ROLE_PREFERENCE_ENABLE

#define CY_APP_ROLE_PREFERENCE_ENABLE   (1u)

Power and Data Role preference control enable.

If this option is disabled, then CY_APP_POWER_ROLE_PREFERENCE_ENABLE should also be disabled.

◆ CY_APP_USB_ENABLE

#define CY_APP_USB_ENABLE   (0u)

Enable/disable the USB feature.

This macro should be set to '1' for solutions that need the USB (Vendor, Billboard and HID) feature support. If this option is disabled, then CCG_BB_ENABLE, CY_APP_USB_HID_INTF_ENABLE and any other macro for enabling USB interfaces should be disabled. CCG_BB_ENABLE should not be disabled if the alternate mode support is needed in the Dock solution.

◆ CCG_BB_ENABLE

#define CCG_BB_ENABLE   (0u)

Enable/disable the Billboard USB feature at the application level.

If the USB feature is disabled CCG_BB_ENABLE shall be also disabled.

◆ CY_APP_USB_HID_INTF_ENABLE

#define CY_APP_USB_HID_INTF_ENABLE   (0u)

Enable/disable the HID USB feature at the application level.

If the USB feature is disabled CY_APP_USB_HID_INTF_ENABLE shall be also disabled.

◆ CY_APP_WATCHDOG_RESET_PERIOD_MS

#define CY_APP_WATCHDOG_RESET_PERIOD_MS   (750u)

Watchdog reset period in milliseconds.

A periodic timer (CY_PDUTILS_WATCHDOG_TIMER) is run using this as a period. This timer resets the device if the main loop has not been run as expected for three consecutive times.

◆ CY_CORROSION_MITIGATION_ENABLE

#define CY_CORROSION_MITIGATION_ENABLE   (0u)

Set this to 1 to enable corrosion mitigation feature By default, SBU lines are used for moisture detection.

Set CY_APP_MOISTURE_DETECT_USING_DP_DM to 1 use DP/DM instead of SBU lines.

◆ APPLE_SRC_EXT_TERM_ENABLE

#define APPLE_SRC_EXT_TERM_ENABLE   (0u)

LEGACY_APPLE_SRC_SLN_TERM_ENABLE should be enabled along with this.
