DFP power sharing

General Description

The DFP power sharing implements a power sharing algorithm for DFP port(s) present on DMC.

The power sharing algorithm aims to provide higher power to dedicated DFP port.

Configuration considerations

The following steps describe the way for enabling the DFP power sharing feature in an application.

  1. Configure the DFP power sharing parameters in main.c file.
  2. Include cy_app_dfp_power_sharing.h to get access to all the functions and other declarations related to this feature.
    #include "cy_app_dfp_power_sharing.h"
  3. Define the following data structure required by application.
    cy_stc_app_dps_context_t DfpPowerSharingCtx;
    cy_stc_app_dps_context_t
    Data structure to hold the DFP power sharing parameters.

  4. Initialize the DFP power sharing algorithm.
    bool isDfpPowerSharingEnabled;
    isDfpPowerSharingEnabled = Cy_App_DfpPowerSharing_Init(&DfpPowerSharingCtx,
    &DfpPowerSharingCfg,
    get_cdtt_config(),
    &PdStackPort1Ctx,
    &HpiMasterCtx,
    DFP_POWER_SHARING_TIMER_ID);
    Cy_App_DfpPowerSharing_Init

  5. Invoke the Cy_App_DfpPowerSharing_Task function from the main processing loop of the application to handle the DFP power sharing tasks.

    {
    if (isDfpPowerSharingEnabled)

    Cy_App_DfpPowerSharing_Task(&DfpPowerSharingCtx);
    }
    }
