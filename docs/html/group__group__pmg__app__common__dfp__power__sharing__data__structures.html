Data Fields
void * portContext PD stack / HPI context of the port.
cy_timer_id_t timerId Timer ID to track updates on the port.
uint8_t eventRcvd: 1 Flag to indicate HPI event received.
uint8_t isPortReady: 1 Flag to indicate port is ready for communication.
uint8_t isCapMismatchSet: 1 Flag to indicate capability mismatch in current RDO.
uint8_t reserved1: 5 Reserved bits.
uint8_t eventCode HPI event code associated with the device.
uint8_t portAddr Port address linked to the DFP port.

-> For DMC port, port address should be 0.
-> For CCGx devices, port address should be I2C address.

uint8_t portState DFP power sharing port state to track the device ready/source PDO update status.
uint8_t retryCount Port retry to track the source PDO update.
