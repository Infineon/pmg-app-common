Swap handling

General Description

The swap handler provides APIs and data structures for evaluating the swap requests.

These APIs are registered as application callbacks and used by the PDStack middleware library.

Features:

  • Data role swap
  • Power role swap
  • Fast role swap
  • VConn swap

Configuration considerations

The following steps describe the usage of the swap handler APIs.

  1. Include swap.h to get access to all functions and other declarations.
    #include "cy_pdl.h"
    #include "cy_app_swap.h"

  2. Initialize the swap functions to the application callback structure.
    /* Register Application callback functions with the PdStack Middleware.
    */
    static const cy_stc_pdstack_app_cbk_t app_callback =
    {
    .eval_dr_swap = Cy_App_Swap_EvalDrSwap,
    .eval_pr_swap = Cy_App_Swap_EvalPrSwap,
    .eval_vconn_swap = Cy_App_Swap_EvalVconnSwap,
    #if CY_PD_REV3_ENABLE
    #if ((!CY_PD_SOURCE_ONLY) && (!CY_PD_SINK_ONLY) && CY_PD_REV3_ENABLE && CY_PD_FRS_TX_ENABLE)
    .eval_fr_swap = Cy_App_Swap_EvalFrSwap,
    #endif /* ((!CY_PD_SOURCE_ONLY) && (!CY_PD_SINK_ONLY) && CY_PD_REV3_ENABLE && CY_PD_FRS_TX_ENABLE) */
    #endif /* CY_PD_REV3_ENABLE */
    };
