PmgAppCommon Middleware Library
PmgAppCommon Middleware Library

The PmgAppCommon asset provides a set of files that are essential for a USB-C and Power Delivery application.The middleware provides the following functionality:

  • Application-level handler for pd stack events
  • Provides the application status information
  • Prepares application layer for device low-power mode
  • Evaluates the source capabilities advertised by the port partner and identify optimal power contract to be entered into
  • Evaluates a PD request data object and determine whether to accept or reject the request
  • Evaluates a power role (PR) swap, data role (DR) swap, or a VCONN role swap request from a port partner
  • Enables/disables power source output
  • Sets the desired voltage and current for the power source output
  • Enables/disables the power sink path
  • Handler for voltage/current change
  • Initializes vendor defined messages (VDM) handler
  • Evaluates the received VDM messages and respond to them
  • Enable/Disable fault protections such as VBUS OVP, VBUS OCP, VBUS SCP, and VCONN OCP
  • Default handlers for fault protections
  • Provides smart power management
  • LED control (e.g., ON, OFF, blink, breath) driver
  • Provides UART and flash based data logging mechanism
  • Dock management controller (DMC) provide support for onboard devices firmware update.
  • USB module provides support for vendor, Billboard, and HID interfaces.
  • Provides support for I2C master mode register read/write.
  • Provides the system level operation (e.g., boot, flash, instrumentation).
  • DFP power sharing feature

The PMGAppCommon middleware is released in source form, while DMC, flash logging, and smart power features are in library form.

General description

Include cy_app.h to get access to all functions and other declarations in this middleware. See the General description to start using the PmgAppCommon.

See the General description section for compatibility information.

See the General description section for change history.

PmgAppCommon operates on top of the PDStack middleware. The PDStack middleware has some prerequisites for proper operation. See the PDStack middleware API reference manual.

Quick start guide

PmgAppCommon middleware can be used in development environments such as ModusToolbox(TM). See the Supported software and tools section.

These steps describe ways about enabling PmgAppCommon middleware in the application.

  1. Open/create an application where to add the PmgAppCommon functions.
  2. Add the PmgAppCommon middleware to your project. This quick start guide assumes that the environment is configured to use the MTB CAT2 Peripheral Driver Library (PDL) and PDStack middleware for development and the PDL and PDStack is included in the project. If you are using the ModusToolbox(TM) development environment, select the application in the Project Explorer window and select the PmgAppCommon middleware in the Library Manager.
  3. Include cy_app.h and other relevant header files from PmgAppCommon middleware to get access to all functions and other declarations in this library.

Feature configuration

PmgAppCommon middleware provides a set of features that can be enabled/disabled at compile time and also customize some of the values used by the middleware through these macros: Feature configuration. These macros are set to default values in the cy_app_config.h file and these can be overridden in the application Makefile.

Weak functions

PmgAppCommon middleware provides a set of weak functions which can be overridden in the solution layer-based on the application requirements. The following are the weak functions provided by the middleware:

Function Description
bool soln_sleep () For putting any solution-specific tasks to Sleep
void soln_resume () For resuming solution specific tasks
void soln_sink_fet_off(cy_stc_pdstack_context_t * context) For turning OFF consumer FET
void soln_sink_fet_on(cy_stc_pdstack_context_t * context) For turning ON consumer FET
void soln_vbus_fet_on (cy_stc_pdstack_context_t *context) For turning ON provider FET
void soln_vbus_fet_off (cy_stc_pdstack_context_t *context) For turning OFF provider FET
void soln_set_volt_port1 (uint16_t vol_in_mv) For setting the regulator output voltage on port 1
void soln_set_volt_port2 (uint16_t vol_in_mv) For setting the regulator output voltage on port 2
